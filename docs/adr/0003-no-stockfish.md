# ADR-0003: Отказ от Stockfish WASM/NNUE в пользу собственного движка

**Статус:** принято (2026-08-21)

## Контекст

Для «большей производительности нейросети» рассматривалась интеграция
Stockfish (WASM/NNUE) как готового сильнейшего движка.

## Решение

Отклонено; усиливаем собственный движок (ADR-0001). Причины:

1. **Размер бандла.** WASM-сборка Stockfish с NNUE-весами — 5–40 МБ.
   Приложение — офлайн-PWA: всё прекешируется на первое посещение,
   десятки мегабайт убивают установку на мобильном трафике.
2. **Лицензия.** Stockfish — GPLv3; приложение коммерческое (подписки),
   интеграция обязала бы раскрыть исходники всей серверной части.
3. **Ресурсы WebView.** NNUE-инференс требователен к памяти; целевые
   Capacitor/Android WebView на бюджетных устройствах страдают.
4. **Избыточная сила.** Продукт — обучающее приложение с уровнями 1–8;
   сила гроссмейстера не нужна, нужна управляемая «персона» уровней —
   Stockfish пришлось бы искусственно ослаблять.

## Последствия

- Собственный движок: ~43 КБ воркер-чанка, полный контроль над персонами
  уровней, глубина 4–6 в бюджете ≤800 мс, маты в 1–2 решаются.
- Если позже понадобятся глубины 7+ — этап 5: собственный 0x88-борд
  (в 5–10 раз больше nodes/sec без изменения публичного API `searchBestMove`).

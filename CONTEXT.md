# M8

Шахматный тренажёр в стиле Duolingo: офлайн-first React + TS приложение
(localStorage как основное хранилище, Supabase опционален). Термины — так,
как их называют спецификация и код.

## Язык

**Урок**:
Единица обучения на карте: 5 задач, первые 3 урока бесплатны (`FREE_LESSON_COUNT`).
_Избегать_: тропинка, глава, курс, этап.

**Тетрадь ошибок**:
Экран повторения: очередь из записей `mistakes` в прогрессе (решённые неверно задачи, дедуп по puzzleId+fen). В коде — ReviewScreen.
_Избегать_: журнал ошибок, история промахов, разбор.

**Спринт**:
Режим «Блиц-спринт» в меню Practice: 3 минуты, максимум задач, неверный ход −10 секунд, рекорд в `sprintBest`.
_Избегать_: блиц, марафон, тайм-атака.

**Генератор матов**:
Бесконечный режим задач «мат в 1 / мат в 2»: позиции выдаёт `src/game/mateGen.ts` (перебор на chess.js по seed + fallback-банк), а не боевой движок и не фиксированный набор задач.
_Избегать_: мат-движок, генератор задач, шахматный движок.

**Дебюты**:
Режим «Тренажёр дебютов»: пошаговое воспроизведение SAN-линии из `src/data/openings.ts` за свою сторону; первое прохождение даёт бонус XP (`openingsStudied`).
_Избегать_: теория дебютов, opening book, уроки дебютов.

**Дивизион**:
Недельная лига против фейковых ботов: поле `leagueDiv` 1|2|3 (1 — золото, 3 — бронза), пересчёт места раз в неделю в `normalize()`.
_Избегать_: лига (лига — вся недельная система с ботами), ранг, рейтинг.

**Админ-панель vs роль admin**:
Панель — локальный экран за паролем (`src/admin/*`, вход по PBKDF2-хешу); роль admin — флаг `profiles.role` в Supabase, дающий право блокировать пользователей по RLS. Панель работает и без Supabase, роль — только в Supabase-режиме.
_Избегать_: админ-аккаунт, встроенный админ (LOCAL_ADMIN удалён), «админка» в смысле роли.

**Локальный режим / Supabase-режим**:
`authMode` приложения: локальный — пользователи и сессии в localStorage; Supabase-режим — auth и профили в Supabase. Оба режима офлайн-first: Supabase-режим не значит «онлайн-игра». Включение определяет `supabaseEnabled`, форс локального — `VITE_LOCAL_ADMIN=1`.
_Избегать_: офлайн-режим/онлайн-режим, серверный режим.

**Прогресс (UserProgress)**:
Профиль достижений игрока в localStorage по ключу `chessup-progress:<userId>`: XP, уровень, Эло, стрик, ошибки, активность. Не путать с профилем Supabase (таблица `profiles`: username, role, banned).
_Избегать_: профиль (без уточнения), сейв, аккаунт.

**Дашборд vs Моя статистика**:
Дашборд — админская сводка по всем пользователям (KPI, активность за 14 дней) во вкладке панели; «Моя статистика» — личный экран игрока из профиля (XP по темам, календарь 8 недель, рекорды). Разные экраны и разные данные.
_Избегать_: статистика (без уточнения), аналитика.

**Промокод (Promo)**:
Код `{code, plan, days, maxUses, uses, active}` в локальном `chessup-promos`; валидация чистой функцией `validatePromo` (нет кода / исчерпан / отключён). Хранится локально — не серверная защита.
_Избегать_: купон, ваучер, инвайт-код.

**План (LocalPlan)**:
Тариф подписки: объект `{plan, until?}` в `chessup-plan:<userId>`, `plan` ∈ free|monthly|yearly|lifetime; `until` в прошлом — free. Старые сохранения могут хранить строку-план — её читают как `{plan}`.
_Избегать_: подписка (это контекст, не поле), премиум-статус, тариф.

**Модель:** сильная

## Что должно заработать

Полная админ-панель: из настроек игрок открывает «Админ-панель», при первом входе задаёт пароль (дважды), дальше — вход по паролю и сессия на 30 минут. Внутри четыре вкладки: Дашборд (KPI + график активности 14 дней + проблемные темы + решаемость), Пользователи (локальные: прогресс, сброс, удаление; Supabase: список, блокировка), Премиум (выдача/отбор плана, промокоды) и Настройки (статус окружения, экспорт/импорт JSON). Игрок вводит промокод на экране Premium и получает план. Встроенный пароль админа из исходников исчезает; заблокированный Supabase-пользователь не может войти.

## Из брифа, дословно

> «добавь систему админпанели» · «и хорошего дашборда» (админ-дашборд — выбор пользователя) · «Да, хеш + смена» (убрать захардкоженный пароль)

Истории 1–12. Решения: админ-аутентификация, данные панели, без новых зависимостей. Контракт — `interfaces.md` (auth.ts, store.ts, компоненты admin/, AuthContext, SubscriptionContext, миграция SQL).

## Критерии приёмки

- [ ] При первом входе панель просит задать пароль (два поля, проверка совпадения), при следующих — только ввести
- [ ] Через 30 минут панель снова требует вход; кнопка «Выйти» завершает сессию сразу
- [ ] Вкладки Дашборд/Пользователи/Премиум/Настройки открываются и не падают при пустых данных (нет пользователей → заглушки с призывом)
- [ ] На дашборде KPI сходятся с данными устройства, график — 14 CSS-баров
- [ ] Сброс прогресса и удаление локального пользователя — с подтверждением; после удаления пользователь не возвращается
- [ ] При выключенном Supabase вкладка пользователей объясняет режим; при включённом — список с ролью и кнопкой блокировки
- [ ] Выданный через панель план сразу виден в UI игрока (корона/подписка); отбор возвращает free
- [ ] Промокод: созданный админом код принимается на экране Premium, исчерпанный/выключенный/несуществующий — три разных понятных ошибки
- [ ] Экспорт даёт JSON со всеми `chessup-*` ключами; импорт после «удалить всё» восстанавливает прогресс
- [ ] Старый пароль админа отсутствует в `src/` и `scripts/` (grep пуст; в scripts/check-admin-login.mjs пароль читается из `process.env.ADMIN_PASSWORD`)
- [ ] Миграция `20261101000000_admin_tools.sql` добавляет `profiles.banned` + RLS для роли admin; заблокированный при входе видит ошибку `loginBanned`
- [ ] `npm run check` зелёный

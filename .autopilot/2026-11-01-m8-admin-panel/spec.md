# Спецификация: M8 — админ-панель, дашборды, новые режимы, чистка

## Задача

Заказчик развивает M8 — шахматный тренажёр в стиле Duolingo. Просит: проанализировать проект, добавить новые функции, убрать нейрослоп (шаблонные тексты и эмодзи-мусор), построить систему админ-панели с хорошим дашбордом и дать идеи для развития. Данные пользователя офлайн-first (localStorage, опционально Supabase) — панель и новые режимы не должны это ломать.

## Решение

Когда всё готово: в настройках появляется «Админ-панель», вход по паролю (задаётся при первом входе, хранится только хешем). Внутри — дашборд с метриками и графиком активности, управление пользователями и премиумом с промокодами, статус окружения и бэкап данных. У игрока — экран «Моя статистика» и три новых режима: Блиц-спринт (задачи на время), Тренажёр дебютов, бесконечный Генератор матов; «Игра с другом» доведена до полной (имена, реванш, счёт серии, отмена хода). README и интерфейс без эмодзи-мусора и устаревших цифр.

## Решения по реализации

- **Генератор матов** — чистый перебор на chess.js (`src/game/mateGen.ts`), не кастомный движок M8: детерминизм по seed, юнит-тесты без воркера. Случайные наборы фигур → проверка легальности → верификация forced-мата перебором; ≤200 попыток → запасной банк из 10 проверенных позиций.
- **Активность для дашборда** — новое поле `activityLog: Record<'YYYY-MM-DD', number>` в `UserProgress`, инкремент в решении задач; `normalize()` дозаполняет новым полям (`activityLog`, `sprintBest`, `openingsStudied`) старым профилям.
- **Админ-аутентификация** — PBKDF2-SHA-256, 100k итераций (та же схема, что у локальных пользователей), соль 16 байт, ключ `chessup-admin-hash`, сессия в `sessionStorage` с TTL 30 минут. LOCAL_ADMIN из `AuthContext.tsx` удаляется; в `scripts/check-admin-login.mjs` пароль читается из `process.env.ADMIN_PASSWORD`.
- **Данные панели** — localStorage плюс существующий клиент Supabase: блокировка — колонка `banned` в `profiles` (миграция + RLS-политика для роли admin), проверка на входе. Промокоды локальные (`chessup-promos`), локальный план хранится как `{plan, until?}` с обратной совместимостью со старой строкой.
- **Новые экраны** — `admin`, `stats`, `openings` в union `Screen` (App.tsx); входы: настройки → админка, профиль → статистика, меню Practice → спринт / дебюты / маты, PlayScreen → улучшенный hotseat. Все новые строки i18n — в оба словаря ru и en.
- **Иконки** — lucide-react (уже в зависимостях); эмодзи-иконки UI заменяются, учебный контент (theory, course, подсказки-хинты как геймплей) не трогается, кроме переписывания дословных дублей.
- **Без новых npm-зависимостей** — графики на CSS/flex, бэкап на Blob/FileReader.
- **Тесты** — mateGen (детерминизм, легальность, верификация мата), admin auth (хеш/проверка/сессия), валидация промокодов (чистая функция), backfill `normalize()`. Gate — `npm run check`.

## Вне рамок

| Требование | Почему не сейчас |
|---|---|
| Редактор контента задач/уроков в админке | пользователь не выбрал его на брифинге |
| Серверная валидация промокодов и серверная выдача премиума | промокоды локальные; серверная часть — следующий заход |
| Переименование ключей `chessup-*` → `m8-*` | миграция данных игроков; отдельная задача (в идеях отчёта) |
| Чистка git-истории (утёк Supabase-токена) | пользователь вращает токен вручную в Supabase Dashboard |
| Push-напоминания, онлайн-мультиплеер, рейтинговые сезоны | идеи отчёта, не эта сборка |
| Ревизия `DESIGN_IMPROVEMENT_PROMPT.md` (устаревший мета-промпт) | служебный документ; отмечено в отчёте |
| Удаление `rus.traineddata` (5 МБ) из корня | файл пользователя; предложено в идеях |

# 05 — Статистика игрока, тренажёр дебютов, игра с другом

**Требования:** R05.2, R02.2, R02.4
**Зависит от:** 02, 03, 04
**Зона:** `src/components/StatsScreen.tsx` · `src/components/OpeningsTrainer.tsx` · `src/data/openings.ts` · `src/components/Profile.tsx` · `src/components/PlayScreen.tsx` · `src/components/PracticeScreen.tsx` (пункт меню дебютов) · `src/App.tsx` · `src/contexts/I18nContext.tsx` (+ тест `src/data/__tests__/openings.test.ts`)
**Волна:** 4
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

Три пользовательских функции. «Моя статистика» — новый экран из профиля: XP по темам, календарь активности за 8 недель, рекорды (выживание, спринт), счёт партий; для нового игрока — дружелюбные пустые состояния. «Дебюты» — из меню тренировки: минимум 6 дебютов (Итальянка, Сицилианка, Ферзевый гамбит, Испанская, Французская, Скандинавская), пошаговая линия с проверкой ходов и пояснением, бонус XP за первое прохождение. «Игра с другом» — режим hotseat доведён до полного: имена сторон, автопереворот доски, счёт серии, «Реванш» и «Отменить ход».

## Из брифа, дословно

> «Тренажёр дебютов» · «Игра с другом» · «и хорошего дашборда» (пользовательский — выбор пользователя)

## Разделы спецификации

Истории 13–14, 17–18, 21. Решения: openings-данные SAN-линиями, валидация через chess.js; hotseat-изменения не затрагивают режим против ИИ. Контракт — `interfaces.md` (openings, OpeningsTrainer, StatsScreen, PlayScreen, App.tsx).

## Критерии приёмки

- [ ] Из профиля открывается «Моя статистика»: темы, календарь 8 недель, рекорды, счёт партий; у нового игрока — пустые состояния с призывом, не «0»
- [ ] Календарь и темы считаются из `activityLog`/`completedPuzzles` и сходятся с фактическими данными
- [ ] В меню тренировки есть «Дебюты»; доступны минимум 6 дебютов на ru и en
- [ ] Верный ход ведёт линию вперёд с пояснением, неверный — повтор; пройденный дебют отмечен «изучено», бонус XP начислен один раз
- [ ] Тест: все линии `openings.ts` легальны в chess.js от начальной позиции
- [ ] Hotseat: имена сторон редактируются, доска переворачивается по ходу, серия W:B:D видна, «Реванш» и «Отменить ход» работают, отмена недоступна в режиме против ИИ
- [ ] `npm run check` зелёный
